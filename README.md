# Edge AI Project

## 1.Introduction
本文记录从零开始做的一些边缘AI的项目，希望能给大家带来帮助。
- **硬件平台**：STM32H747I-DISCO
- **开发环境**：STM32CubeMX, STM32CubeIDE, STM32CubeAI,VSCode
- **机器学习框架**：TensorFlow Lite for Microcontrollers
## 2.Project 
每个项目会分为两个部分，model文件夹内是关于训练调整模型的相关代码，以基于TensorFlow库的Jupyter Notebook格式为主；test文件夹内是关于在开发板上实践的项目，以CubeMX和CubeIDE的工程文件为主，实践的代码全部在TouchGFX配置的基础上修改，所以可能内存很大。
