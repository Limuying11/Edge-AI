# Project1 人类活动识别

## 1.硬件
1. 开发板：STM32H747I-DISCO(自带屏幕)
2. 六轴传感器MPU6500：获取xyz轴加速度

## 2.软件
1. VSCode & TensorFlow:对ai模型进行训练和测试
2. STM32CubeIDE 1.18.0:进行数据读取和模型使用
3. STM32CubeMX 6.14.0:进行I2C,USART1和ai配置,对ai模型进行验证
4. X-CUBE-AI 10.0.0:进行ai的调用的API
5. TouchGFX 4.25.0：屏幕显示

## 3.功能
1. I2C读取6轴传感器数据，获得xyz轴加速度数据（float类型）
2. 把24组xyz加速度数据传递到ai相关的函数中进行识别
3. 把读取到的24组加速度数据和识别出的四种类型的概率值传递到串口进行显示
4. 四种状态各自制作了一个界面，把识别出的四种类型在屏幕上显示出来
