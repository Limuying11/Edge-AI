# Human activity recognition model

这个项目在官方给的模型上进行修改,官方只提供了HDF文件和YAML文件,个人还是喜欢在Python上进行模型的训练,所以在官方HDF文件和YAML文件的基础上,把官方模型以Jupyter Notebook格式展现，帮助大家充分理解模型和进行自己的模型训练。

dataset为数据集，ign.h5为官方的模型，ign,yaml为官方的YAML文件，HAR.ipynb为ign.h5的模型导入和训练生成新的h5文件的代码，

官方https://github.com/STMicroelectronics/stm32ai-modelzoo/tree/main/human_activity_recognition
